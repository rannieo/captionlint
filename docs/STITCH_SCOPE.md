# Stitch Screen Scope Map

Source project: https://stitch.withgoogle.com/projects/15181293185028918235

This map keeps Stitch design usage aligned with `docs/PRD.md`.

## MVP Screens To Implement Now

- CaptionLint Home / Landing
- Upload / New Lint Run
- Lint Results
- Linting History
- History Detail / Re-fix
- Vocabulary Rulesets
- Pricing placeholder
- Sign In / Create Account shell
- Basic Settings shell

## Gated Future Screens

These may remain behind feature flags or as reference only until the MVP workflow is complete.

- Projects Portfolio
- Create New Project
- Project Configuration
- Workspace Settings beyond basic profile/billing shell
- Onboarding Workspace Setup
- Onboarding Ruleset Configuration
- Onboarding Success
- Team Invitation
- Documentation pages
- Integrations pages

## Out Of MVP / Reference Only

These should not appear in public MVP navigation or copy.

- API Playground
- CLI Reference
- Advanced integrations
- Audit/compliance detail screens
- Team management screens
- Batch or automation workflow screens

## Implementation Rule

Use Stitch for layout density, dark color system, badges, tables, and data-first UI. Do not use Stitch screens to expand MVP scope beyond `Upload captions -> choose preset -> run QA -> review issues -> export`.
